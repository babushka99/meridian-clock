# Changelog

All notable changes to this project are listed here. Versions follow
[Semantic Versioning](https://semver.org/).

## [1.1.0] — 2026-10-21

First public release, as **Meridian Clock**.

- Live day/night world map with a ruler of up to ten saved cities.
- Planning mode: convert any date and time from any city, with safe handling of daylight-saving
  gaps and repeated hours.
- Add city search (~6,000 cities), Manage panel, per-dot map labels, 12h/24h, dark/light theme.
- The map fills the full window width on wide screens (polar caps are cropped).
- Country borders and the hour grid stay readable on the night side in both themes.
- Extra map labels give way (the dot stays) instead of overlapping on crowded, narrow layouts.
- Fully offline; only the `storage` permission.
